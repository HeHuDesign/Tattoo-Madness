# Tattoo Madness: project guide for Claude Code

This file is the full story of this project so far. Read it before making changes. The owner is Milton, who is learning as he goes: explain what you are doing in plain language, show changes before making them, and commit working states often.

## What the game is

Tattoo Madness is a cozy pixel-art game about a tattoo apprenticeship. The look is inspired by farm-sim games like Stardew Valley, but every asset is original and drawn in code. Never copy art, characters or names from Stardew Valley or any other game.

The game has three parts:

1. **Apprenticeship.** The player walks into a tattoo shop and meets their mentor, Dee. Dee explains the rules, then the player practices on six fake-skin pads that get harder: Smiley, Heart, Star, Anchor, Dagger, Rose. No clock.
2. **First customers (Days 2 and 3).** Seven scripted NPC customers, each with their own design, body spot, dialogue and a loose timer. Running over time lowers the tip but the customer stays. Supplies (needles, ink, wraps) start being used here; Dee hands over a starter kit at graduation.
3. **Your own shop (career mode).** After the apprenticeship ends, the player runs the shop: walks around the floor, chooses customers from the waiting bench, buys supplies, upgrades and staff at the counter, and saves up to buy other shops on the town map.

There is also a **Free tattoo** sandbox from the title menu (no scoring, color inks, upload your own stencil).

## How to build and run

- After any change to `www/`, run `npm run sync` (copies www/ into the Android project). Without it, the app keeps the old version.
- Milton then presses Run in Android Studio with his phone plugged in (USB debugging on).
- `npm run android` = sync + open Android Studio.
- You can also open `www/index.html` directly in a desktop browser for quick testing. Mouse, keyboard and a USB controller all work there.

Toolchain: Node.js 22+, Capacitor 8 (`@capacitor/core`, `cli`, `android` 8.x), Android Studio with **Gradle JDK set to jbr-21** (Java 21), Android SDK 36. Don't accept the "New Gradle version available" upgrade prompt; Capacitor's template pins its own version.

## Architecture of www/index.html

Everything is plain JavaScript inside one IIFE, no build step, no frameworks, no external network requests. The script is organized into sections marked with banner comments like `/* =============== TATTOO ENGINE =============== */`. In order:

| Section | What it does |
|---|---|
| CSS (top of file) | Wood/parchment UI panels (`.wood`), buttons (`.gbtn`, `.gbtn.go` = green primary), screens, controller highlight (`.pad-focus`), and a `.compact` block for short landscape phone screens |
| DESIGNS | Each tattoo design is an SVG path string (`d`) in a 600×600 coordinate space plus a tolerance `tol` (how far off the line you can be). Helpers `circ()` and `starP()`. `PRACTICE` lists the six practice pads in order |
| CHARACTERS | `CH` maps character ids to looks (hair, skin, shirt colors, hair style, beard, tattoos, apron). `CUSTOMERS` holds the seven scripted apprenticeship customers with dialogue (`hi`, `dee`, `react[0..3]`) |
| SAVE | `SAVE_KEY='tattooMadness.v1'` in localStorage. `fresh()` defines every save field. `persist()` writes |
| AUDIO | Web Audio machine buzz while inking (`buzz(on)`), short UI beeps (`blip(freq)`) |
| PIXEL SPRITES | Characters are 10×16 pixel maps built in `spriteRows()` from a base body plus style changes. `drawSprite()` draws at 2x; `drawPortrait()` draws the head for dialogue/HUD portraits |
| SCENE RENDERER | Low-res canvas `#scene` (about 320×180, scaled up with pixelated rendering). `drawExterior()` = title screen shop at dusk with the "TATTOO SHOP" neon sign. `drawInterior()` = inside the shop. `actors` array + `updateActors()` walk characters around; `walk()` returns a promise |
| SCREENS / UI | `show(id)` switches screens (`#scr-title`, `scr-shop`, `scr-board`, `scr-tattoo`, `scr-results`, `scr-controls`, `scr-end`, `scr-floor`, `scr-store`, `scr-map`, `scr-dayend`). `modal(text, buttons)` returns a promise. `say(who, text)` is the typewriter dialogue box (await it). `fade()`, `dayCard()`, `toast()` |
| INPUT MODE | `inputMode` is `'mouse' | 'touch' | 'pad'`. Controller menu navigation: `focusables()`, `moveFocus(dir)`, `setPadFocus(el)` |
| TATTOO ENGINE | The drawing station. Canvases inside `#pad`: `cShade` (shading layer), `cLine` (linework, used for scoring), `cBuf` (stroke buffer for the liner), `cDirt` (aftercare grime), `cWarn` (red boundary), `cSten` (purple stencil, multiply blend). Tools in `TOOLS` (liner, shade, erase, cloth) with needle sizes like 3RL–14RL and 7M1–31RM. Strokes: `strokeBegin/Move/End` → `interp()` → `stamp()` with smoothing, tapering and pressure (pen pressure, mouse speed, or controller RT). `layoutPad()` sizes and zooms the skin |
| Boundary / slips | `buildMasks()` makes `job.strikeMask` (the allowed zone = stencil line widened by `tol + STRIKE_PAD`) and draws the red boundary on `cWarn`. Ink outside it → red warning, then a **slip**. On fake skin the pad is wiped and the player restarts; 5 slips fail the round. On a real customer (`isClient`) the bad ink stays, and 3 slips (`job.maxStrikes`) = they walk out with no retry (`failRound()` → `showFail()`) |
| Body parts | Real customers are inked on a drawn body part, not the pad: `BODY[spot]` shapes, `drawBody()` paints `cBody` (1200×1200 covering skin coords −300..900 so limbs run off screen), `.pad.body` CSS drops the pad frame. `job.body` = the spot. Every shape must keep x 55..545 on skin |
| Warm-up | `offerWarmup()` asks before every client (also has a Supply counter button); `startWarmup()` runs mode `'warmup'` (fake skin, customer's design, no clock/supplies; 15 game minutes per try in career). `warm.start()` begins the real tattoo |
| Ink meter | `job.inkAcc` adds up skin area inked in `stamp()`; `inkUsed()` = 2 ml + 1 ml per 1000 px² (max 25), `inkLeft()` = bottle minus that. `renderInk()` draws the meter; at 0 `outOfInk()` stops the machine and offers the counter. `backToStation()` returns from the counter to the same tattoo (clock paused meanwhile) |
| Smudges | On real skin, `smudgeTravel()` drops a smudge (ink + blood blobs on `cDirt`) every ~220–340 px of needle travel, max 6. `tickSmudges()`: "Clean up!!" at 2.5 s, at 6 s it sets in for −3 points (max −30, `job.smudgePen`). Wiped with the `towel` tool (W key, X cycles to it) → "Stay clean!!". `withSmudges()` applies the penalty to the score |
| Aftercare | `job.phase`: `'ink'` → `'wash'` (cover choice modal) → `'care'`. `startAftercare()` auto-washes, then the player picks ointment + plastic wrap or second-skin film and rubs/smooths it over `careMask()`; `carePct()` = coverage. `wrapUp()` turns coverage into healing (`healInfo`): film ×1.1, no ointment ×0.75, no wrap ×0.6, −5% per late smudge |
| Scoring | `scoreWork()` returns coverage (how much of the stencil got traced), accuracy (how much ink is on the line), score 0–100 and stars: 90+ = 3, 78+ = 2, otherwise 1. A finished round is never 0 stars; only a failed round is. `finishJob()` blocks submitting below 70% coverage. `payRate(score)` sets a real customer's pay: under 70 = nothing (and −1 rep), 70–77 = 10–50%, 78–89 = 50–85%, 90+ = 85–100% |
| Shading + colors | Designs with a `shade` area (smiley face, heart, star, dagger blade, rose bloom, moon) can get a shading step after the lines (`startShadeStep()`, `job.shadeStep`) when the job has a `shadeSpec`: a list of parts `[{part:'all'/'left'/'right'/'top'/'bottom', color}]`, split at the middle of the area. `PALETTE` = black, red, blue, green, yellow, purple; the palette (`#shadeInks`) shows in the shading step and whenever the Shader is picked on a job with colors (`setTool()`), and the shading step always starts on black (`pickShadeColor()`). Guide = each part tinted its color, dashed split line. `scoreShade()` checks fill, spill and the right color per part (`wantColor()`, `nearestColor()`); final score = 60% lines + 40% shading. Linework is always black outside Free mode. Practice: `PRACTICE_SHADE` (Heart red, Star yellow, Dagger blade half black/half blue), Dee says the colors. Scripted customers have `shade` in `CUSTOMERS`; career customers get `randomShade()` 60% of the time (pay ×1.25, longer) |
| Apprenticeship flow | Six pads; Heart, Star and Dagger include shading (see above). Picking a pad walks you to the practice desk (`goPractice()`, `deskSpot()`); no free walking during pads. After pad 2, `openBoard()` runs `robberyLesson()` once (`save.robTut`): the Comply/Hide/Fight box shows all three but only Fight can be picked (modal button 4th item = disabled). `save.shadeStars` is left over from an earlier version, unused |
| Fight engine | `runFight({lesson,count})` → screen `scr-fight` over the interior scene. All robbers (`rob1..3`) walk in at once (the lesson has 1) and weave toward the register, sidestepping shots they see coming (`FT.dodge`). You move (joystick, WASD, left stick / D-pad) and aim: touch/mouse = press and drag (dotted aim line, `FT.aiming`), release to `shoot()`; controller = right stick aims, RT/A shoots; Space shoots at `FT.aim`. A shot during the cooldown is queued (`FT.queued`). Robbers have 4 HP and shoot back (`FT.eshots`, −12 health per hit, your health `FT.hp` = 100, shown as a bar); Dee shoots from behind the counter every ~2 s and misses about 60%. Robbers go to the register (`r.state` 'in'), grab the cash for 1.2 s ('grab', money bag drawn), then run for the door ('out'); they can still be stopped on the way out. Lose = health gone (`FT.lostBy='hp'`) or a robber gets out the door with the cash (`'escaped'`). Dee tosses the gun first (`tossGun()`, drawn by `drawFx()`). Resolves true/false |
| Joystick | `#joy`, see-through, bottom left, shown on `floor` and `fight` unless a controller is in use (`showJoy()`); `joy.x/joy.y` feed `floorTick()` and `fightTick()` |
| Dee's floor (Days 2–3) | `F.appr` = walkable Dee's shop before career: no clock, door blocked. `deeTour()` once (`save.toured`), then `spawnScripted()` brings `CUSTOMERS[save.cust]` in one at a time; `talkScripted()` → customer walks to the chair → `startCareerJob()` (shared with career) offers the warm-up, `playerWalk()` shows you walking to the desk or chair. `afterScriptedJob()` after results/fail. Scripted customers have a patience bar in real seconds (60 for Pip, 45 after), paused while anyone talks; Dee explains it the first time (`deeWaitBar()`, `save.seenWaitBar`). If it runs out, `scriptedWalkout()`: they leave for good, −1 rep, `save.cust++`. Time keeps passing while a box is open or you're walking (`passiveTick()`: career clock / Dee's patience; only paused while someone talks). ### Game rules and numbers worth knowing

- Design coordinate space `DOC = 600`. Tolerances: smiley 7, heart and star 6, the rest 5.
- Practice pads unlock one at a time; any finished round (1+ star) unlocks the next. Stencil opacity drops as pads get harder.
- Aftercare: after inking a real customer, a final wash, then ointment + plastic wrap or a second-skin film rubbed over the whole tattoo. Healing 85%+ = heals fast (+rep, best pay), 60–85% = normal, under 60% = infection risk (−rep).
- Supplies per tattoo: 1 needle (2 if the shader was used), 3–25 ml ink depending on how much was inked, then 1 ointment + 1 plastic wrap, or 1 film. Assistants use ointment + wrap. Dee's starter kit: 4 needles, 40 ml, 3 wraps, 4 ointment, 1 film.
- Career day: starts 9:00 (`DAY_START`) with the doors CLOSED (`F.open`); open/close at the door or menu (`setDoors()`); customers only arrive while open, until 22:00 (`CLOSE`/`LAST_IN`). The day ends only via "End the day" (`endDayAsk()`) or automatically at midnight (`DAY_END`). 4 game minutes per real second on the floor, and also while you're away on the map or at the Supply Store (`F.away` → `offFloorTick()`: clock, patience, arrivals, staff, and the tattoo timer if you left mid-tattoo with `job.onRun`).
- Supplies: the counter is now the **supply closet & office** (`openStore('closet')`: view stock, upgrades, staff). Buying supplies only happens at the **Supply Store** (`SUPPLIER`, blue blip on the map, `openStore('supplies')`; ~20 min trip in career; open 8 AM–6 PM in career via `supplierOpen()`, grey blip and a "closed" card otherwise). There are **no shortcut buttons**: you walk to the front door, head out (city map) and find the store yourself. The "▼ Supply Store" marker shows only until the first purchase (`save.runTut`), i.e. on Dee's errand. Mid-tattoo, the station menu / out-of-ink box offers **Step out** (`stepOut()`: back to the floor with the client in the chair, `F.suspended`, their tattoo timer keeps running); walk back to the chair ("Back to your client", `resumeJob()`). While suspended you can't take other clients, end the day or change shops. On Days 2–3, after customer 2, Dee empties the ointment/wrap, gives 60 coins and sends you on a run while the next customer walks in (75 s patience; `deeRunCheck()`, `F.runAsk`; that customer can't be started until you've bought something); Dee reacts on your return.
- Old career rule, kept for reference: Your own tattoo jobs jump the clock forward by the design's duration. Customers arrive faster with more reputation and the neon upgrade; harder designs (and better pay) unlock with reputation (`DES_INFO[design].rep`).
- End of day: rent `rentToday()` = the shop's rent (Dee's shop 50, other shops 40–390, raised about 1.5× in Oct 2026) + 5 per extra bench seat + 15 per extra chair. No rent while Dee is alive. The morning day card shows "Rent due tonight", staff wages, income from owned shops, healed reviews (due 1–3 days after the tattoo depending on cleanliness).
- Assistants: Mika (skill 60), Bo (80), Sage (95). Each needs an extra tattoo chair. They auto-take waiting customers and use your supplies; a red "!" over them means out of supplies.
- Town map shops: Harborside Ink 800, Old Mill Studio 2,000, Neon Alley Tattoo 4,500, Hilltop Atelier 9,000 coins; each adds daily income.

- **Bodies and paramedics:** a robber who gets shot down stays on the floor (`FT.bodies` from `endFight()`, kept on the shop floor in `F.bodies`). About 18 s later (`F.ambT`), `paramedics()` sends two medics (`medic1`, `medic2`) in to carry the body out (`a.carriedBy`). In the first robbery lesson, Dee calls it in and the medics come right away.
- **Weapons on screen:** armed actors (`a.armed`) show their weapon outside fights too (`drawHeld()`). `weaponOf()`: Dee's killer (`rob5`) carries a shotgun that fires a 3-pellet spread; the other robbers carry pistols.
- **Dialogue box** only shows on scene screens (floor, shop, fight). `show()` hides it on all other screens.
- **Dev skips** (floor menu, dev mode only): in career, "skip 2 hours" and "end the day now"; on Days 2–3, "skip this customer".
- **Dee's death scene (reworked):** no camera zoom at all (`CAM`/`camFocus()` are still there but unused). The killer came for Dee, not the money. You run to the register for the gun (`playerWalk`), then kneel to the right of Dee's head and apologize. Right after Dee dies, the paramedics carry Dee out and a police officer (`CH.cop`) says they're searching for the shooter. You close the doors and the day ends; there's no option to keep the shop open.

Known overlap: a 3rd extra chair sits on the practice desk (fix in 3C furniture moving).

Bodies stay until someone calls (`F.ambCalled`, `F.ambT`). A customer who leaves over a body costs −1 rep. Dee's robberies (lesson and Day 3) call the paramedics right away.
- **Customers:** each career customer gets a patience range: hurried 110–150, normal 160–230, patient 240–340 game minutes. Negative rep now slows arrivals (`arrivalGap()`).
- **Robberies scare customers off:** `robberyScatter()` (called at the start of `runFight()`, when the Day 3 robber pulls his gun, and when Dee's killer walks in) makes every customer, even one in a chair, run out the door (`a.run` = double walk speed) with an "EEK!/RUN!" bubble. Staff tattoos in progress stop unpaid. Your own client mid-tattoo (`F.jobCust`) stays.
- **Dee's death fight:** the shot plays in slow motion with three visible pellets (`CUTSHOTS`, drawn in `drawFx()`). Then the fight starts with no gun (`runFight({noGun:{x,y}})`): you move to the gun at the counter yourself (`FT.noGun`; shooting before that just says "Get the gun first!"). Meanwhile the killer holds his ground and shoots at you (`r.state='hold'`, `FT.dmg` 7 per hit), then runs 2.5 s after you grab the gun (or after 9 s if you never do). The clock is paused during the whole scene (`F.deathRunning`), so midnight can't end the day mid-scene and bring Dee back.
- **Depth and prompts:** the practice desk is drawn in depth order with the people (`drawDesk()`), so you walk behind its lamp and pad. The lamp and plant block all the way up to the wall. The door hotspot is just "Door" (`door:true`), with no pink arrow over it. On touch, the prompt button has no "Tap:" prefix. The map's Supply Store tag has no ▼.
- **Title screen:** no subtitle. After quitting a game, the title keeps showing the shop you were in (`show()` keeps `sceneMode` 'interior' while `save.started`).
- **Health and hospital:** `save.hp` (`hpNow()`). Career fights start at max(40, your health) and leave you with what's left (`endFight()`). ## Controls (all must keep working for every new feature)

- **Mouse / touchpad:** drag to ink; moving slowly makes a heavier line. Keys: L/S/E tools, [ ] needle size, T stencil, F full view, Esc pause. On the shop floor: WASD/arrows to walk, E/Space to interact, M map, Esc menu. Click the floor to walk there.
- **Touch:** finger drags ink; a stylus gives real pressure. Tap the floor to walk; tap a person or the counter to walk over and use it.
- **Controller (Gamepad API, standard mapping):** left stick moves the machine cursor, RT inks (pressure from how hard it's squeezed), LT slows the cursor for detail, X swaps tool, LB/RB needle size, Y stencil, Start finishes, L3/R3 full view, B pauses at the station. D-pad moves the gold highlight between any buttons on screen; any face button selects. On the shop floor the stick/D-pad walks and any face button interacts; Start opens the menu.

**Hard requirement:** every new button or menu must be reachable with a controller. Use real `<button>` elements inside the active screen or modal; `focusables()` picks them up automatically. Disabled buttons are skipped.

## Phone layout rules

The Android app runs fullscreen in landscape. Typical phone viewports are about 800×360 to 915×412 CSS pixels.

- Nothing should ever need scrolling. Use the `.compact` CSS block for short screens, and `fitAll()` shrinks anything that still doesn't fit. If you add a new panel, put it inside `.dim > .wood` (or the title `#tfit`) so it gets fitted automatically.
- At the tattoo station in compact mode, the info panel is on the left, tools on the right, and the skin fills the middle. `layoutPad()` zooms in on the design's bounding box (`designBox()`) so the design fills the screen height. `job.vis` is the visible area, used to keep the controller cursor on screen.
- Full view (`setFull()`) hides both side panels; the floating "☰ Tools" button and a mini status chip bring them back.
- Test new screens at 800×360 and at a tablet size like 1280×800.

## Lessons learned (don't repeat these)

- **Never put a `//` comment in the middle of a line.** The code packs several statements per line; a mid-line `//` silently disables everything after it. It once switched off `bctx.arc(); bctx.fill()` in `stamp()`, so no ink appeared at all. Put comments on their own line or at the very end. When testing drawing, simulate real pointer events on `#pad`, not just `strokeBegin()` calls.
- **Pixelify Sans joins "fi" into a broken letter** ("film" showed as "Alm"). `body` has `font-variant-ligatures:none`; keep it.
- **Gamepad edge detection:** `pollPad()` snapshots the previous button state into `prev` *before* overwriting `gp.prev`. A past bug overwrote it first, so no press ever registered as new: tracing worked (held buttons) but menus didn't.
- **Face buttons differ between controllers.** PlayStation, Nintendo and generic pads report "A" as button 0, 1 or 2. That's why any face button selects in menus.
- **Android turns a controller's B button into the system back key.** MainActivity routes back to `__tmBack()`, which ignores it if a controller button was pressed in the last 400 ms (`gp.lastPress`) so B isn't handled twice.
- **CSS `display:none` on a canvas** in the stylesheet means `style.display=''` won't show it; use `'block'` (this hid the aftercare grime once).
- **OneDrive breaks Gradle builds** ("Cannot snapshot ..." errors). Keep the project in `C:\dev`.
- **Re-unzipping the project resets Android Studio's JDK choice.** To update the game, change `www/` only.

## Known issues and loose ends

- "Save PNG" is hidden in the app; it only worked in the original Claude web preview. Saving to the phone's gallery would need a Capacitor plugin (Filesystem or Share).

## How to work on this project

- Before a non-trivial change, say in plain words what you plan to change and why.
- Keep everything in `www/index.html` unless there's a real reason to split it. No frameworks, no build step, no network calls (the app must work offline).
- Keep the art style: original pixel art drawn in code, warm wood-and-parchment UI, the Pixelify Sans font.
- After changing the game: run `npm run sync`, tell Milton to press Run in Android Studio, and list what to test (touch, mouse and controller).
- When a change works, offer to commit it with a clear message. If something breaks, `git` can roll back to the last commit.
- Don't modify `android/app/src/main/assets/public/` by hand, and don't upgrade Capacitor or Gradle without asking.
